# Cycling Training Evidence Library

**Evidence review date:** 2026-08-31  
**Purpose:** A local, app-ready evidence base for designing cycling, strength, mobility/yoga, stretching, recovery, fuelling and monitoring features.

This library deliberately separates **research evidence** from **coaching convention**. It is designed to be ingested by a training app or read by a human coach/developer.

## Where to start
1. Read `00_START_HERE.md`.
2. Use `research_database.csv` for browsing and `research_database.json` for app ingestion.
3. Read `app_logic/training_principles.md` and `app_logic/evidence_rules.json` before implementing an algorithm.
4. Use `sample_plans/` and `sample_plans/workout_library.csv` as examples, not fixed prescriptions.
5. `source_notes/` contains one concise note per curated source.

## Copyright / papers
The archive contains **original summaries, metadata and links**, not copies of closed-access journal articles. Open-access status is recorded so you can legally retrieve full text from the publisher/repository. This keeps the library portable without redistributing copyrighted PDFs.

## Safety
This is a sports-training evidence resource, not medical diagnosis or treatment. The app should stop/modify training and direct users to qualified medical care for acute illness, chest pain, fainting/dizziness, unexplained breathlessness, suspected injury, persistent performance deterioration, or RED-S/eating-disorder concerns.
