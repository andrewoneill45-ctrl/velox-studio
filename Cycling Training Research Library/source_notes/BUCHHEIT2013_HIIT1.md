# High-Intensity Interval Training, Solutions to the Programming Puzzle: Part I: Cardiopulmonary Emphasis

**Citation:** Buchheit M; Laursen PB (2013). *Sports Medicine*.  
**Type:** Narrative review  
**Population:** Athletes  
**Directness:** Endurance/applied physiology  
**Evidence grade:** B  
**Open access:** No / check publisher access  
**DOI / source:** https://doi.org/10.1007/s40279-013-0029-x

## What it adds
HIIT responses are determined by multiple variables including work duration, intensity, recovery duration, recovery intensity and modality.

## App implication
Model interval workouts as a parameter set, not a single label. Match work/recovery configuration to the targeted physiological response.

## Tags
HIIT, programming, VO2max

## Interpretation caution
This is a concise evidence note, not a reproduction of the paper. Apply findings according to athlete calibre, intervention duration, sex representation, event demands and study limitations. Where the source is not cycling-specific, directness is explicitly downgraded.
